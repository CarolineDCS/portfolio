## Pipeline DBT

* This is my first independent DBT project. I had to create an ELT pipeline to make Airbnb data from Amsterdam usable for analysis. 
I first prepared Snowflake to retrieve the data. Then I developed the pipeline using templates and macros, while testing the data quality as thoroughly as possible, in order to dispatch the data to final tables. I also proposed four analyses. I hope this project is comprehensive enough to allow you to perform your own analyses on Airbnb data from Amsterdam.
  * You can find it [here](https://github.com/CarolineDCS/projet_airbnb_DBT)

## Pipeline Snowflake

* This is my first independent Snowflake project. I had to create an ELT pipeline to integrate logs from a fictional healthcare application.
I first worked on governance, setting up a hierarchical RBAC model and creating the data structure (databases, RAW/COMMON/STAGING schemas, tables, internal stage).
I then developed the pipeline via Tasks (TASKS) with DAGs, functions/procedures to validate quality (processes/dates) and dispatch to final tables, which I found very interesting.

  * You can find it [here](https://github.com/CarolineDCS/snowflake_pipeline)



* Ceci est mon premier projet Snowflake en autonomie. Je devais créer une pipeline ELT pour intégrer des logs d’une application de santé fictive.
J’ai d’abord travaillé sur la gouvernance, en mettant en place un modèle RBAC hiérarchique et en créant la structure de données (bases, schémas RAW/COMMON/STAGING, tables, internal stage).
J’ai ensuite développé la pipeline via Tâches (TASKS) avec DAGs, fonctions/procédures pour valider la qualité (processus/dates) et dispatcher vers les tables finales, ce que j’ai trouvé très intéressant.

  * Vous le trouverez  [ici](https://github.com/CarolineDCS/snowflake_pipeline)

## Projet powerBI -- Call center

* This is my first Power BI project without instructions. I have to create a dashboard about several call centers for the director of these centers. The data was real anonymized data. 
I imported the data. I prepared the data. I reorganized the data into a star schema. And I created my main dashboard and two secondary tables. 
I found this work interesting because I had to choose the best charts for informed management. I'm not sure about the result, but it was a good exercise.

  * You can find it [here](https://github.com/CarolineDCS/PF-Analysis-and-Reporting-Project-for-Outsourced-Call-Center)

* Ceci est mon premier projet Power BI en autonomie. Je devais créer un dashboard pour le directeur d’une société de centres d’appel. Les données étaient des données réelles, mais anonymisées.
J’ai d’abord travaillé sur les données, afin de vérifier qu’il n’y ait pas d’incohérence et de les réorganiser selon le modèle en étoile.
J’ai ensuite passé beaucoup de temps pour essayer plusieurs graphiques afin de sélectionner ceux qui seraient le plus parlant pour prendre des décisions. Ce que j’ai trouvé très intéressant.
Je ne suis pas certaine du résultat, mais j’ai trouvé cet exercice très formateur.

   * Vous le trouverez  [ici](https://github.com/CarolineDCS/PF-Analysis-and-Reporting-Project-for-Outsourced-Call-Center)
